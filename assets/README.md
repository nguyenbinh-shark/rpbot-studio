# Icon RPBot Studio

- `rpbot-studio.ico`: icon cửa sổ, taskbar, EXE và shortcut trên Windows (16–256 px).
- `rpbot-studio.png`: dấu 40 px ở thanh đầu và trang Giới thiệu.
- `rpbot-studio-256.png`: icon cửa sổ và menu ứng dụng trên Linux.

Hình robot nhìn từ trên với vòng quét LiDAR, màu đen/xanh của `studio_theme.py`.
Các file được vẽ bằng `tools/make_icon.py` (cần Pillow). Muốn đổi hình thì sửa
script đó rồi chạy lại, không sửa tay file ảnh.
